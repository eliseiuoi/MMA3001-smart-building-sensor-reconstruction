# MMA3001-smart-building-sensor-reconstruction
Numerical methods for reconstructing missing environmental sensor measurements in smart buildings.

## Project Overview

This project investigates numerical methods for reconstructing missing
environmental sensor measurements in the Monash Smart Infrastructure Lab.

The initial investigation focuses on time-series environmental data including
temperature, humidity, CO2 concentration and pressure.

## Current Project Question

How accurately can missing environmental sensor measurements be reconstructed
using different numerical interpolation methods?

## Dataset

The dataset was provided by the MMA3001 teaching team.

Primary dataset:
`Env_data_MSI_Lab - 30-07-2025_19-12-2025.csv`
